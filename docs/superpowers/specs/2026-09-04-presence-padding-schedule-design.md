# 접속 인원 보정 시간표 설계

## 목표

지도의 접속 중 인원 표시에 적용하는 무작위 보정값을 KST 요일과 시간대에 맞게 조정한다.

## KST 시간표

| 조건 | 보정 범위 |
| --- | --- |
| 매일 00:00 이상 08:00 미만 | `+0` |
| 평일(월~금) 09:00 이상 18:00 미만 | `+1~+5` |
| 평일 08:00 이상 09:00 미만 | `+0~+3` |
| 평일 18:00 이상 24:00 미만 | `+0~+3` |
| 주말(토·일) 08:00 이상 24:00 미만 | `+0~+3` |

모든 요일·시간 판정은 브라우저와 서버의 로컬 타임존에 관계없이 `Asia/Seoul`을 기준으로 한다. 08:00과 09:00, 18:00 경계를 위 범위대로 명시적으로 처리한다.

## 생성과 표시

- 기존 실제 접속 인원 수집 방식은 유지한다.
- 순수 함수가 현재 시각의 KST 구간에 맞는 보정 최솟·최댓값을 반환한다.
- 기존 무작위 정수 생성 방식을 유지하되, 새 구간의 포함 범위 안에서만 생성한다.
- 한 시간대 구간 안에서는 보정값을 재생성하지 않고, 00:00·08:00·09:00·18:00 중 다음 실제 범위 변경 경계에서만 새 보정값을 생성한다.

## 변경하지 않는 부분

실제 접속 인원 쿼리, 접속 상태 갱신, 화면 문구, 분석 이벤트, 데이터베이스는 변경하지 않는다.

## 검증

고정된 시각을 사용하는 순수 함수 테스트로 평일·주말과 00:00, 08:00, 09:00, 18:00 경계를 검증한다. 생성된 보정값이 각 구간의 최솟·최댓값을 벗어나지 않는지와, 다음 범위 변경까지의 대기 시간이 정확한지도 확인한다.
