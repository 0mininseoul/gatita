# 설정 화면 문구 간소화 설계

## 목표

설정 화면의 기숙사생 선택과 푸시 알림 영역에서 반복되거나 작은 설명 문구를 제거해 핵심 조작을 더 빠르게 읽히게 한다.

## 기숙사생 섹션

- `기숙사생이신가요?` 제목을 유지한다.
- `같이타에 가입한 다른 기숙사생들과 동행 요청을 주고 받을 수 있어요` 소개 문구를 유지한다.
- `네`/`아니요` 버튼과 기존 선택·저장 동작을 유지한다.
- 버튼 아래의 `‘네’를 선택하면...` 동의 안내 문구는 제거한다.

## 알림 섹션

- 섹션 제목 `알림`을 유지한다.
- 사용자에게 보이는 행 텍스트는 `푸시 알림 (채팅, 경로 알림 등)` 한 줄만 남긴다.
- `참여 중인 채팅방에...`, 알림 차단 안내, 미지원 브라우저/PWA 설치 안내를 모두 제거한다.
- 푸시가 지원되면 기존 토글 동작과 저장 로직을 유지한다.
- 푸시가 차단되거나 미지원이면 같은 텍스트와 비활성 토글을 보여 레이아웃을 일관되게 유지한다.
- 토글의 접근성 이름도 화면 문구와 동일하게 변경한다.

## 변경하지 않는 부분

기숙사생 설정 API, 푸시 구독·해제, 권한 요청, Amplitude 이벤트, 데이터 스키마는 변경하지 않는다.

## 검증

설정 화면 계약 테스트에서 새 푸시 문구가 존재하고 제거 대상 문구는 존재하지 않으며, 제어 핸들러는 유지되는지 확인한다.
